---
title: What pagebldr is
description: An embeddable visual page-building engine for React applications.
---

`pagebldr` gives a React Host a controlled visual editor and an SSR-capable
production renderer. It owns the portable Document, commands, validation,
migrations, Local history, Elements, styles, rendering, and optional lifecycle
orchestration.

Your application keeps control of authentication, permissions, persistence,
routes, publication policy, Resources, events, and deployment. `pagebldr` is not
a CMS or hosted service.

## Choose your integration

- Start with [the five-minute quickstart](/docs/quickstart) for
  callback-controlled local persistence.
- Add the optional server module when you want standardized saves, optimistic
  concurrency, Revisions, and publication pointers.
- Use the Runtime to resolve Published pages from Host-owned routes.
