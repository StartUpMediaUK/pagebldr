---
title: Package exports
description: Choose the smallest supported entry point for each runtime.
---

- `@startupmedia/pagebldr` — configuration and shared public contracts.
- `@startupmedia/pagebldr/library` — the 23 neutral standard Block factories; no
  Templates.
- `@startupmedia/pagebldr/react` — controlled React editor and renderer
  interfaces.
- `@startupmedia/pagebldr/react/server` — SSR-safe presentation renderer.
- `@startupmedia/pagebldr/server` — optional framework-neutral lifecycle
  orchestration.
- `@startupmedia/pagebldr/runtime` — published-route resolution and analytics
  preparation.
- `@startupmedia/pagebldr/styles.css` — compiled editor styles and theme
  variables.

Use only package export paths; filesystem paths inside the package are private.
