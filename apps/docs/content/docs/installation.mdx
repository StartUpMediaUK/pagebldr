---
title: Installation
description: Install pagebldr and its React peers.
---

```bash
pnpm add pagebldr react react-dom
```

Import the compiled package styles once in your application:

```tsx
import "pagebldr/styles.css";
```

React 18.3 and React 19 are supported. The editor does not require Tailwind,
shadcn, ReUI, Next.js, a database, or an external account in the Host.
