# Security policy

## Supported versions

`pagebldr` has not released a supported version yet. This policy will list
supported release lines before the first public alpha.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for the `StartUpMediaUK/pagebldr`
repository. Do not open a public issue containing an exploit, credential,
private document, or personal data. Include affected versions, reproduction
steps, impact, and any suggested mitigation.

The maintainers will acknowledge a complete report, coordinate remediation, and
publish an advisory when disclosure is safe. No bounty is promised.
