# Support

Before the first public alpha, use GitHub Issues for reproducible bugs and
focused feature proposals. Include a minimal reproduction, runtime versions,
framework, browser when relevant, and the exact `pagebldr` version or commit.

Security reports follow [SECURITY.md](SECURITY.md). Product-specific database,
authentication, tenancy, and deployment support belongs in the Host project
unless the behavior reproduces through `pagebldr`'s public interface.
