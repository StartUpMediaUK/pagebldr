# Private Template testing fixtures

These six package-native Documents characterize source editor behavior. They are
testing material for the private Reference Host, not a catalogue distributed
with `pagebldr`. Package code must not import this directory. Hosts supply their
own Templates through the public definition and library-source interfaces.

The product owner confirmed this scope on 2026-10-07. No source image binaries
are copied here. Historical media filenames are opaque test Resource references;
the Reference Host resolves them to original geometric illustrations. The
owner's recollection of Unsplash provenance is not verified permission to
redistribute Quizr's `public/templates` images.

The packed-artifact check scans output and source maps for fixture identifiers
and source image filenames. These fixtures are copied separately into the
temporary Reference Host for browser verification, not installed from the npm
archive. Do not advertise their visual content as bundled package functionality.
