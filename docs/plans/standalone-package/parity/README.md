# Parity acceptance index

Parity work uses these documents as one acceptance system:

- [Acceptance cases](acceptance-cases.md) — stable behavior IDs mapped to the
  source-of-truth study.
- [Interaction traces](interaction-traces.md) — complete packed-package browser
  journeys.
- [Visual matrix](visual-matrix.md) — fixed viewports and screenshot states.
- [Reference Host contract](reference-host-contract.md) — installed-consumer
  purity, routes, Adapters, seed data and evidence requirements.
- [Target Documents](../../../../fixtures/parity/README.md) — immutable neutral
  data fixtures.

An audit must identify case IDs, trace IDs, visual IDs and fixture names rather
than claiming broad feature completion without evidence.
